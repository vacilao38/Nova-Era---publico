_E aqui onde você prepara a sessão de fato_

> aqui ainda nao tem nada, mas se voce utilizar a paleta de comando, puxando de cima para baixo rapidamente na area da nota, vai aparecer uma lista de comandos, procure por `Modelos: inserir modelo` e selecione `Preparar Sessão` para inserir aqui o modelo pronto de sessão. Voce pode criar uma pasta para armazenar as sessoes que vc prepara aqui na area de trabalho, basta fazer isso e renomear a corretamente para ficar facil de achar.
