### Fases da Lua
As datas se propagam para todos os meses.

| fase da lua                  | dia         |
| ---------------------------- | ----------- |
| Lua Nova                     | Dia **01**  |
| transição para Lua crescente | Dia **05**  |
| Lua Crescente                | Dia **08**  |
| transição para Lua Cheia     | Dia **11**  |
| Lua Cheia                    | Dia **15**  |
| transição para Lua Minguante | Dia **19**  |
| Lua Minguante                | Dia **22**  |
| transição para Lua Nova      | Dia **26**  |

Para calcular a fase de qualquer noite, o estado indicado permanece até o próximo marco do ciclo:

| Dias do mês | Fase observável à noite |
| ----------- | ------------------------ |
| 01–04 | Lua Nova |
| 05–07 | transição para Lua Crescente |
| 08–10 | Lua Crescente |
| 11–14 | transição para Lua Cheia |
| 15–18 | Lua Cheia |
| 19–21 | transição para Lua Minguante |
| 22–25 | Lua Minguante |
| 26–28 | transição para Lua Nova |

### Regra para datas relativas

- Somar dias sem contar o dia do marco inicial.
- Depois do dia 28, continuar no dia 01 do mês seguinte.
- Depois do mês 10, continuar em 01/01 do ano seguinte.
- Exemplo canônico: a derrota de [[Odr]] ocorre em 24/06/0387; portanto, o 12º dia depois é 08/07/0387 e o 24º dia depois é 20/07/0387.
